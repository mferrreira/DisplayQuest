# DisplayQuest Component Patterns

## Page header

A page header consists of:

- optional visual/icon;
- title;
- short description;
- contextual primary action.

The title is visually dominant.

The description is quieter.

## Summary block

Summary blocks are compact and information-oriented.

They may contain:

- icon;
- label;
- primary value;
- secondary information;
- contextual action.

They should remain compact.

## Project item

A project item is a horizontal information-rich unit.

It may contain:

- project icon or image;
- project name;
- status;
- description;
- tags;
- progress;
- members;
- dates;
- contextual menu.

The entire item should read as one coherent object.

Avoid splitting each field into its own nested card.

## Task card

Task cards are compact and information-dense.

They may contain:

- task title;
- tags;
- responsible person;
- date;
- status-related information.

The task title should remain the strongest textual element.

## Kanban column

A Kanban column contains:

- column title;
- task count;
- add action;
- task cards.

The column has a subtle visual distinction from neighboring columns.

Different semantic statuses may use restrained accent colors.

## Activity item

Activity entries are compact chronological records.

They may contain:

- avatar;
- person's name;
- action;
- referenced object;
- relative time.

Avoid turning every activity into a large card.

## Deadline list

Upcoming deadlines should be presented as a compact list.

Use semantic color to distinguish urgency/status.

## Gamification panel

Gamification information may contain:

- level;
- progress toward next level;
- points;
- badges or achievements.

It should feel integrated into the product rather than like a separate game UI.

## Filters

Filters should form a coherent toolbar.

Related controls should be grouped together.

Avoid scattering filters throughout the page.

## Contextual actions

Use compact menus or subtle controls for secondary actions.

Do not turn every possible action into a prominent button.
