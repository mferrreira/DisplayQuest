# DisplayQuest UI Anti-Patterns

Avoid the following visual patterns unless the existing product explicitly requires them.

## Generic AI dashboard

Do not create a page consisting primarily of:

- three or four metric cards;
- several colorful charts;
- rounded containers everywhere;
- excessive gradients;
- decorative statistics.

The reference uses dashboard elements, but the actual work area remains the focus.

## Card explosion

Do not put every section inside a card.

Do not create:

- card inside card;
- card inside card inside card.

Use whitespace, borders and section hierarchy when a card is unnecessary.

## Excessive pills

Tags and statuses may use compact rounded badges.

Do not turn ordinary controls, navigation or arbitrary text into pills.

## Excessive color

Do not assign a different bright color to every element.

Accent colors exist to establish semantic hierarchy.

## Excessive shadows

Avoid large floating shadows.

The reference relies primarily on borders, spacing and surface contrast.

## Decorative gradients

Do not introduce gradients merely because they make the interface look more "modern".

## Decorative artwork

Do not use illustrations, stock-style artwork or handwritten type.

The references carry their identity through layout, typography and the token palette, so there is no artwork language to imitate.

## Decorative clutter

Do not fill empty space with arbitrary widgets, charts, statistics or motivational text.

## Excessive minimalism

Do not remove useful information simply because the result looks cleaner.

The references are information-rich.

## Inconsistent components

Do not create a new visual treatment for an existing concept when an existing component can be reused.

## Visual overengineering

Do not add animations, effects, gradients or decorative elements without a clear visual reason.

The interface should feel polished but calm.

## Screenshot imitation

Do not reproduce the reference as a static composition.

The implementation must remain dynamic and adapt to real content.
